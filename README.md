SISTEMA DE RENTA DE VIDEO - EVALUACIÓN CONTINUA - HITO 3 

1. Descripción del proyecto

Implementación de un sistema de renta de video utilizando MongoDB como sistema de gestión de base de datos NoSQL.

El sistema permite administrar clientes, artículos, alquileres, devoluciones y pagos, además de generar informes administrativos y resúmenes de ingresos.

2. Tecnologías utilizadas

- MongoDB
- MongoDB Compass
- MongoDB Shell (mongosh)
- Git y GitHub

3. Base de datos

Nombre: "SistemaRentaVideo"

Colecciones:
- clientes
- articulos
- rentas
- pagos

4. Procesos implementados

1. Renta de video.
2. Elaboración de informes para Administración.
3. Retorno de artículos rentados.
4. Resumen de ingresos totales.
5. Registro de nuevos clientes.

5. Instalación y ejecución

1. Instalar MongoDB.
2. Abrir MongoDB Compass o MongoDB Shell.
3. Crear la base de datos SistemaRentaVideo.
4. Ejecutar los archivos JavaScript en orden.
5. Verificar los registros y resultados de las consultas.

6. Resultados

El sistema permite almacenar, consultar y actualizar información de clientes, artículos, rentas y pagos, facilitando el control administrativo y contable del negocio.
